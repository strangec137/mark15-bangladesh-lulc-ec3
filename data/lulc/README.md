# LULC data

This folder needs the ESA WorldCover 2021 tiles for Bangladesh (10 m, two tiles):

- `LULC_ESA_WorldCover_Bangladesh-0000000000-0000000000.tif`
- `LULC_ESA_WorldCover_Bangladesh-0000065536-0000000000.tif`

They are git-ignored because of size. Download both from this repo's
[Releases](../../../releases) page (tag `v1.0`) and place them in this folder before running
the notebook.
